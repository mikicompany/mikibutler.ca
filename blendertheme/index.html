A free Blender theme maker in your browser

Changing Blender's interface colours by hand means digging through dozens of widget, panel and 3D-viewport settings in Preferences. This Blender theme editor does it visually: pick colours, watch a full mock Blender window — menus, tool shelf, outliner, properties and the 3D viewport — recolour in real time, then export a theme .xml you install in one click. It's free, needs no account, and runs entirely in your browser, so nothing you make is uploaded anywhere.

What you can do

  • Live full-window previewSee every menu and panel update as you pick colours.
  • Export install-ready .xmlA real Blender 4.x theme file for Preferences ▸ Themes ▸ Install.
  • Import & editLoad an existing theme .xml and tweak it.
  • Starter presetsDark, Light, Nord, Dracula and more to build from.

How to install a Blender theme (.xml)

  1. Design your theme above and click Download .xml.
  2. In Blender, open Edit ▸ Preferences ▸ Themes.
  3. Click Install… and choose your .xml file — it applies instantly.
  4. The file name becomes the theme's name in the Themes preset dropdown, so you can switch back any time.

Frequently asked questions

Is the Blender Theme Maker free?

Yes — completely free, no account or signup, and it runs entirely in your browser. Nothing is uploaded.

Does it export a real Blender theme file?

Yes. It exports a standard Blender theme .xml. Install it via Edit ▸ Preferences ▸ Themes ▸ Install and it applies right away.

Which Blender version does it support?

The exported .xml targets the Blender 4.x theme format.

Can I edit an existing Blender theme?

Yes — use Import .xml to load a theme you already have, adjust the colours live, and export it again.

Does it upload or store my data?

No. Everything happens locally in your browser; your theme only leaves your machine when you download the file.
