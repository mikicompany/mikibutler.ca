Protected Content Encryptor

Local tool — run the site with python serve.py and open http://localhost:8321/tools/protect.html. Paste the items to protect, choose a password, and save the output as protected-data.json in the site root. Nothing here is ever sent anywhere; encryption happens in your browser.

⚠️ Images referenced by img still upload to the public repo if you commit them there. For real NDA material, host images at an unguessable external URL and reference that URL here instead.

Editing the existing gallery? Enter the password above and click Load & decrypt current data to pull the live items into the box below. Reorder / add / remove as needed, then Encrypt. The password stays in your browser — nothing is sent anywhere.
